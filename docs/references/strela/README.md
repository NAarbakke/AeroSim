# Strela User Manual

NPO Mashinostroyenia, *Strela Launch Vehicle User Manual*, Second Edition, 1999 (63 pages).
`profile/` holds the specs, reference trajectory and payload curves extracted from it.

The manual is marked as NPO Mashinostroyenia proprietary and is **not included in this
repository**. Save a copy here as `180618736-Strela.pdf`; `.gitignore` keeps it out of commits.
