# Long March 2C User's Manual

China Academy of Launch Vehicle Technology (CALT), *LM-2C User's Manual*, Issue 1999 (flight
record updated to March 2002, 156 pages). `profile/` holds the specs, trajectory and payload
curves extracted from it.

Every page is marked "CALT'S PROPRIETARY", so the manual is **not included in this
repository**. Save a copy here as `16906331-China-s-Long-March-2C-Users-Manual.pdf`;
`.gitignore` keeps it out of commits.
