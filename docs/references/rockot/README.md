# Rockot User's Guide

Eurockot Launch Services GmbH, *Rockot User's Guide*, EHB0003, Issue 5, Revision 0,
August 2011 (220 pages). `configs/orbital/rockot.yaml` and the Rockot briefing are based on it.

The guide is copyrighted by Eurockot and is **not included in this repository**. Download it
and save it here as `Rockot_Users_Guide_EHB0003_Iss5_Rev0_2011.pdf`; `.gitignore` keeps it
out of commits.
