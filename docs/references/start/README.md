# START-1 User's Handbook

STC Complex-MIHT, *START-1 Space Launch System User's Handbook*, Volume I (SC & LV
interfaces), Issue 1, May 2002 (70 pages). `profile/` holds the specs, trajectories and payload
tables extracted from it.

The handbook is **not included in this repository**. Save a copy here as
`START-1_user_handbook_vol1.pdf`; `.gitignore` keeps it out of commits.
