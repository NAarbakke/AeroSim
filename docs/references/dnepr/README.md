# Dnepr User's Guide

ISC Kosmotras, *Dnepr Space Launch System User's Guide*, Issue 2, November 2001 (76 pages).
`profile/` holds the specs, payload curves and flight sequence extracted from it.

The guide is ISC Kosmotras material and is **not included in this repository**.
Save a copy here as `Dnepr-User-Guide.pdf`; `.gitignore` keeps it out of commits.
